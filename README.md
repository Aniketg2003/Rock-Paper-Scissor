## 📖 About The Project

This is a simple, interactive web-based game where you test your luck against a computer opponent. Make your choice—Rock, Paper, or Scissors—and see if you can beat the computer! The game features a clean user interface and uses images for a more engaging experience.

### ✨ Features

* **Play against the computer:** Test your skills against an automated opponent.
* **Instant Feedback:** See the result of each round immediately.
* **Visual Interface:** Uses clear images for Rock, Paper, and Scissors choices.
* **Responsive Design:** (Optional: Add this if your CSS makes it mobile-friendly).

## 🛠️ Built With

* **HTML5**: For the structure of the game (see `index.html`).
* **CSS3**: For styling and layout (see `style1.css`).
* **JavaScript**: For game logic, computer choice generation, and determining the winner (see `game.js`).

## 🎮 How To Play

1.  Open the game in your web browser.
2.  Click on one of the three options: **Rock**, **Paper**, or **Scissors**.
3.  The computer will randomly make its own choice.
4.  The winner is decided based on the classic rules:
    * 🪨 **Rock** crushes ✂️ **Scissors**
    * ✂️ **Scissors** cuts 📄 **Paper**
    * 📄 **Paper** covers 🪨 **Rock**
5.  The result (Win, Lose, or Draw) is displayed on the screen.
